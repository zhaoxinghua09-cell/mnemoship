## Definition

**Mnemoship** — the governing rule that the memory and identity of an autonomous thing must be **portable**: able to move between runtimes, vendors, and generations without loss of continuity.

An autonomous thing is not its model. Models are copyable — weights can be cloned, prompts can be copied, skills can be forked. What **cannot** be copied is the accumulated memory plus the permissions bound to it. Whoever holds that pair holds the identity.

Mnemoship states that this pair must be **exportable, importable, and verifiable**:

- **Registry (LGD-I)** — the memory-holder is registered as a person-like household (人格户籍), not as a file blob.
- **Evidence (LGD-II)** — portability must be *provable*: an export artifact whose fingerprint is stable across languages and runtimes.
- **Gate (LGD-III)** — the transfer must pass gates: consent → integrity check → destination admissibility → continuity confirmation.

## Why the term was coined

*Memory Sovereignty* is **abandoned on both sides** — the Chinese phrase is held by a company plus patents and copyright registrations; the English phrase is occupied by an arXiv paper. This was not a naming preference; it was a collision finding, verified and recorded.

The concept space itself is crowded: Stanford projects, a MacPaw standard proposal, PAM specifications, an MS arXiv paper. Every descriptive English name collides.

**Mnemoship** names the property — *the condition of having portable memory* — rather than competing for a phrase others already own. The descriptive subtitle carries search; the coined term carries the claim.
